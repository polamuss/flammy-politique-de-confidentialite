Politique de Confidentialité

1. Introduction

Cette politique de confidentialité décrit la manière dont Flammy (le bot et le site) collecte, utilise et protège les données personnelles des utilisateurs.

2. Données collectées

Le bot Flammy peut collecter les données suivantes uniquement dans le cadre de ses fonctionnalités :

  • ID Discord des utilisateurs
  • ID des serveurs
  • Dates d'anniversaire des utilisateurs (si ajoutées volontairement)
  • Informations liées aux votes ou paramètres du serveur (ex: salon d'annonce, de départ, etc.)

Aucune donnée sensible n'est collectée.

3. Finalité de la collecte

Les données sont utilisées uniquement pour fournir les fonctionnalités proposées par le bot : système d'anniversaire, niveaux, votes, messages personnalisés, etc.

4. Conservation des données

Les données sont conservées uniquement pendant la durée d'utilisation du bot sur un serveur. Si le bot est retiré ou si l'utilisateur demande la suppression de ses données, elles seront supprimées manuellement ou automatiquement selon le cas.

5. Partage des données

Les données ne sont partagées avec aucun tiers. Aucune donnée n'est vendue, louée ou transférée à une autre entité.

6. Sécurité

Des mesures techniques sont mises en place pour sécuriser les données stockées et limiter les accès non autorisés.

7. Cookies

Le site flammybot.com n'utilise pas de cookies de suivi ou à des fins commerciales. Uniquement des cookies techniques peuvent être présents pour le bon fonctionnement du site.

8. Vos droits

Vous pouvez demander à consulter, modifier ou supprimer vos données à tout moment. Pour cela, contactez-nous par mail à : contact@flammybot.com
